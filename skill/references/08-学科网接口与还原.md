# 学科网取材：接口、坑与还原（对照 GitHub 上的现成项目）

> 这一篇是把 GitHub 上能搜到的学科网/组卷网项目逐个读完源码后的结论，
> 加上我自己实测过的部分。**能直接用的接口都标了实测结果**，不能用的写清为什么。

## 一、GitHub 上有哪些现成实现

| 仓库 | 类型 | 核心做法 | 我借鉴了什么 |
|---|---|---|---|
| `flt6/tools`（`zxxk_dl/main.py`） | Python 脚本 | 直接调**预览 JSON 接口** `FirstLoadPreviewJson`，拿到整份 HTML（含 RAR 多文件） | ★ 这个接口是本轮最大收获，见下 |
| `rong6/BetterZujuan` | 浏览器扩展 | 组卷网导出 PDF/DOCX，**公式转 Word 原生公式对象**、按页显示尺寸插图、按尺寸识别「假图」 | 思路：导出要保留公式可编辑性；图片有效性要校验 |
| `Frank-678/zxxk-zujuan-paper-downloader` | 油猴脚本 | 恢复 `data-src`/`data-original` 懒加载、图片转 Data URI、ZIP 分题 | 懒加载属性还原（`data-original` 就是预览页 URL 的载体） |
| `isping/zujuan-export` | 油猴脚本 | LaTeX→Unicode、图片内嵌 base64 | 轻量导出的最小实现 |
| `bzyzh/xkw-zujuan-script`、`ljj13/ZuJuanWang` | 油猴脚本 | 页面净化 + 打印 | 打印样式分离 |
| `malyjacob/zujuan` | Node/Playwright | 组卷网按知识点抓题、截图 + 视觉 OCR | 截图+OCR 是公式保真的另一条路（成本高） |

**结论**：所有能跑的项目都绕不开两件事——① 预览/题目其实是**矢量或位图渲染**，
不是结构化数据；② 想要「可编辑」，就得把渲染结果**反向还原**（或用浏览器截图 + OCR）。
没有谁拿到过学科网的结构化题库 API（那需要登录态与付费权限）。

## 二、关键接口（实测 2026-10）

### 1. 预览 JSON（推荐入口）

```http
GET https://www.zxxk.com/soft/Preview/FirstLoadPreviewJson
    ?softID=<documentId>&type=3&product=1&v=2&FullPreview=true
Referer: https://www.zxxk.com/soft/<documentId>.html
```

返回：

```json
{"code":0,"success":true,"data":{
  "IsSuccess":true,"IsRar":true,
  "rarPreviewInfo":[
    {"SoftName":"…（原卷版）.docx","PreviewPage":2,"TotalPage":5,
     "Html":"<img data-original=\"https://cdn-preview.xkw.com/…/svg/1.svg?Expires=…&Signature=…\">…"},
    {"SoftName":"…（解析版）.docx","PreviewPage":3,"TotalPage":23,"Html":"…"}
  ]}}
```

要点：
- **`PreviewPage` 是免费能看的页数（2–5 页），`TotalPage` 是全本页数** —— 别把 PreviewPage 当全本。
- 每份资料常含**多个文件**（原卷版 / 解析版），各自有独立的页列表与页数。
- 页面 URL 带 `Expires` + `Signature`，**不能自己拼**，只能用返回的。
- 一次成功后就该**缓存**（内容不会变）。实测连续请求第 2 次就会撞阿里云**滑块验证**。

### 2. 预览页本身

- 格式：**SVG**，`viewBox="0 0 793 1122"`（A4 @96dpi）。
- 文字：`<text x="172.3 182.9 193.4 …" y="116.1">2026-2027</text>`——**x 是逐字形的坐标列表**。
- 字号：常挂在父级 `<g font-size="21">`，`<text>` 自己不写。
- 公式/几何图：`<image x= y= width= height= xlink:href="data:image/png;base64,…">`——**内嵌 base64**，
  所以「公式是图片」不是缺陷，是可以直接抠出来复用的素材。
- 还有一层 **y=0 的隐藏文本**（整页文字副本）和页脚水印「学科网（北京）股份有限公司」，必须剔除。

### 3. 详情页（辅助）

`https://www.zxxk.com/soft/<id>.html` 里有 JSON-LD（标题/学段/年级/版本/页数/作者/是否免费），
以及最多 5 个 `cdn-preview` URL。**只用于拿元数据**，页列表以 JSON 接口为准。

## 三、三个必须处理的坑（都实测过）

1. **WAF**：`search.zxxk.com` 走 `alicfw`/`acw_sc__v2` 两套 JS 挑战，Node 跑页面 JS 可解；
   `Preview/FirstLoadPreviewJson` 触发的是**阿里云滑块验证**（`aliyunCaptcha`），脚本解不了 ——
   所以只能「一次成功 + 落盘缓存」，不要重试轰炸。
2. **坐标**：`x` 是列表、`font-size` 在 `<g>` 上、还有 y=0 隐藏层。三条都踩过，
   处理完才得到正确的行序（否则数字会跑到行首，整页乱掉）。
3. **页数**：免费预览固定截断（常见 2–5 页），`TotalPage` 才是全本；
   要全本只能下载原件（登录 + 点数）。

## 四、jszz 现在怎么做

| 能力 | 工具 | 说明 |
|---|---|---|
| 版本清单 | `zxxk_preview_files(document_id)` | 原卷版/解析版 + 预览页数 + 全本页数 |
| 读正文 | `zxxk_preview_text(document_id, version=0, max_pages=0)` | 默认读该版本**全部可预览页** |
| 还原 docx | `zxxk_preview_docx(document_id, version=0)` | 文字可编辑 + 公式图形位图 |
| 抠图 | `zxxk_preview_images(document_id, version=0)` | 导出公式/几何图，做 PPT 素材 |

实测（60192049 广州十校联考数学卷）：原卷版 2/5 页、解析版 3/23 页；
还原 docx 拿到 1 065 字 + 45 张内嵌图；图片导出 66 张。

## 五、和 GitHub 项目的差距（如实）

- **公式不是 Word 原生公式对象**：BetterZujuan 把 OMML 做出来了（132 个公式对象），
  我这里仍是位图。要补这一块，需要把 SVG 的 `<text>`+路径重建成 OMML，工作量很大，
  当前先用「位图 + 可编辑文字」，够老师改题干、改选项。
- **不做整册下载**：原文件要账号点数，jszz 不绕过付费。
- **组卷网仍受限**：机房 IP 常被直接阻断，学生/老师家里的宽带有较大概率可用。
