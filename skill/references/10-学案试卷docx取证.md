## 答案版学案（重点，已实现 `answers=True`）

真实答案版（第9课学案答案、《师说》复习题答案版）的写法：

| 元素 | 真实样式 |
|---|---|
| 挖空处答案 | **红色**文字直接压在原下划线上，**不加粗**（`w:color=C00000` + `w:u`） |
| 小标题「知识点一：…」 | **蓝色加粗**（实测 `#0000FF`） |
| 「学习聚焦」「1. 概念」 | 黑色加粗行内标签 |
| 答案后接解析 | 「答案：D」加粗 + 「解析：…」整段 |
| 页脚 | 「试卷第 X 页，共 Y 页」居中 |

生成：`make_xuean(answers=True)` / `jszz xuean --answers` → 额外出
`{名}-答案版.docx`，标题自动加「（答案版）」。

## 页眉（四栏 + 分隔线）

真实学案页眉一行四栏：`学校+年级+学科+学案名+课号 | 编写人：xx | 审核：xx组 | 时间：yyyy.m.d`
（实测「胶州四中高二历史选必三学案第9课　编写人：李晓　审核：高二历史组　时间：2026.3.7」），
文字下有一条**横贯版心的细分隔线**。jszz 用无框两列表格 + 底边单线实现。

## 试卷（物理月考卷实测）

- 标题居中加粗，**日期小字紧贴标题右侧**；下一行「(时间: 90 分钟　满分: 100 分)」括号居中
- **没有密封线、没有班级姓名考号栏**（另一份化学卷有三栏底框线——两种风格都真实存在，
  jszz 保留三栏版，更正式；出简单卷时可省）
- 大题说明连写跨行：「一、单项选择题(本题共8小题，每小题3分，共24分。在每小题给出的
  四个选项中，只有一项是符合题目要求的。)」
- 选项排布：**短选项 2×2、含公式/长选项单列竖排**（物理卷每项一行，A、B、C、D、顿号）
- 图嵌题干右侧或下方；公式 Times 斜体
- 页脚居中「第 X 页（共 Y 页）」

## 教师用卷（答案内嵌）

`【答案】`/`【解析】` 标签**红色**，紧跟题后；答案可带「（非官答）」标注；
题源写法「1．（2026·河北高考·14）」——年份·省份·卷别·题号。

## PPT 第二批补充观察（史地政 + 写作/实验课型）

- 历史一轮封面：**大图背景（压暗）+ 巨型标题两行错位** + 右上小字定位信息
- 物理实验封面：蓝渐变 + **半透明圆角底板标题卡**（保证白字可读）
- 地理封面五段式：年份条(橙) + 学科大字(蓝) + 专题胶囊(橙) + 主题(黑) + 学校胶囊(蓝)
- 章节过渡页：巨大序号 `01` + 栏目名 + 副导航小字，三行递减
- 英语练习页：黄底黑字题型徽章 + 正文内嵌红色词组注释（不另开词汇表）
- 三色语义全场一致：黑=正文、红=核心/答案/纠错、蓝=条目/知识块
