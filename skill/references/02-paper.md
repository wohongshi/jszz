# 试卷规范（来自 147 份试卷类文档、32 份可解析真卷的统计）

## 一、成品形态

- A4 竖版，页边距 1.8–2.0cm，题干 11.5pt（真卷常用五号~小四），行距 1.45
- 标题 18pt 加粗居中；`（时间：90分钟　满分：100分）` 紧随其下（10.5pt 灰）
- 班级 / 姓名 / 考号：三栏各一条底框线（表格实现，不是连续下划线）
- 大题标题 12pt 黑体加粗左对齐
- 页脚：学校 + 「第 X 页 共 Y 页」

## 二、结构模板

真卷里出现频率最高的两种大题写法：

```
选择题：本题共 10 小题，每小题 2 分，共 20 分。          （7 份）
非选择题：本题共 5 小题，共 60 分。                     （7 份）
```

分值表述模板统计（括号内为出现次数）：

| 模板 | 次数 |
|---|---|
| 本题共 N 小题，每小题 N 分，共 N 分 | 21 |
| 本题共 N 小题，每小题 N 分，共 N 分（无空格版） | 17 |
| 本题共 N 小题，共 N 分 | 10 |
| 本题共 N 小题，共 N 分（无空格版） | 5 |

结构要素命中率：选择题 30、非选择题 30、答题卡 11、考试时间 10、满分 9、
第Ⅰ卷/第Ⅱ卷 6–8、注意事项 7、答案/详解 6+3。

**结论：一份卷子只写「一、单项选择题 / 二、多项选择题 / 三、非选择题」三节即可，
不用强行分第Ⅰ/Ⅱ卷**（山东卷近年多为一卷到底）。

## 三、题量与配比（山东高中常见）

| 学段 | 配置 |
|---|---|
| 高三 100 分 | 8 单选 ×3 = 24；4 多选 ×4 = 16；4 非选择 = 60（12+14+16+18） |
| 高二 100 分 | 10 单选 ×3 = 30；5 多选 ×4 = 20；4 非选择 = 50 |
| 单元测 100 分/60 分钟 | 9 单选 ×4 = 36；4 非选择 = 64，或 8+4+60 |

高考语文/英语按 150 分：现代文阅读 35 + 古诗文 35 + 语言文字运用 20 + 写作 60。

## 四、排版硬规则

1. **选项默认 2×2**（真卷主流）；四项都很短（合计 ≤38 字宽）才排成一行四列。
   绝不把某个选项拆成两行——渲染器按字符宽度估算，超宽就换布局。
2. **题干续行悬挂缩进 0.74cm**，续行与题干正文左缘对齐，不能顶到页边。
3. `（　　）` 答题括号用不换行空格，避免「（　　）」单独掉到下一行。
4. 答案页 `---` 另起，标 `【答案】A`、`【解析】…`，解析用浅底纹。
5. 图：题干里的图放正文中间，宽 9cm；图题 9pt 灰字居中。
6. **数学符号防拆行**：数字与单位之间用不换行空格（渲染器自动处理），
   `（　　）` 答题括号也绑成不可分单元，避免括号单独掉行。
7. **答案速查表**：答案页顶部自动生成「题号行 + 答案行」的表格（每行 8 题），
   老师对答案一秒钟扫完，再往下看详细解析。

## 五、命题质量（教师视角）

- 一节 8 道单选要覆盖 4–6 个知识点，最后一题做区分度
- 多选题的干扰项要「错得有理」，不要出现明显荒谬项
- 非选择题按「(1)(2)(3)」递进，第 (3) 问才是区分点
- 每题在 Markdown 里可带 `> 来源：2026 山东卷第 8 题`，方便溯源

## 五·二、答案解析与阅卷分析（430 份深读，试卷转讲评必备）

**答案四段式**（选择题逐项说理，不是只给结果）：

```
1．（2025·全国Ⅰ卷）…题干…
【答案】B
【分析】…（命题意图/考什么）
【解答】A：…，排除。B：…，正确。…
【点评】…（方法一句话）
```

设误类型点名：`张冠李戴` `无中生有` `程度夸大` `因果倒置` `以偏概全`——
`"必然规律"属于程度夸大，表述绝对化……绝对化词语一般都是陷阱`。
多选末尾汇总 `故选 BC`；答案速查表 `1--8：DCCB CDAB` 挂答案页顶部。
翻页式答案（课件）：**题干页整页留白，下一页整页答案**，不在题干页内联。

**阅卷分析五段式**（试卷讲评/质量分析的骨架，顺序固定）：

```
一、试题分析（命题立意 / 命题特点 / 思路解析）
二、评分标准（逐点标分 + 负面边界）
三、学生答题优点
四、存在的突出问题（错答画像）
五、备考提示
```

- 开头带统计：`本题满分13分，最高分13分，最低分0分，平均分6.31分`
- 错答画像要具体到学生答法：`大量学生认为东汉画像石和清代石碑为一手史料导致失分`
- 英语讲评逐题给「原文定位 → 翻译 → ✅答案 → 干扰项硬伤」，
  末尾空格校验：`36空校验结论：只有 B 成立；其余6项均有明确硬伤。`

## 六、自检清单

- [ ] 大题标题写了「共 N 小题，每小题 N 分，共 N 分」
- [ ] 选项没有断词、没有单选项换行
- [ ] 题干续行有悬挂缩进
- [ ] 有班级/姓名/考号三栏
- [ ] 答案另起一页，解答题有步骤
- [ ] 满分加起来等于标题里的总分
