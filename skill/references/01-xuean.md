# 学案规范（来自 25 份真实学案的统计）

## 一、成品形态（按真学案逐项量过）

- A4 竖版，页边距 1.8–1.9cm，正文**宋体 12pt**，行距 1.5，首行缩进 2 字
- 标题：16pt 加粗居中
- **页眉**：左「学校+年级+学科+学案」，右「编写人／审核／时间」，9pt 黑体加粗
  （真学案都有页眉，这是最容易漏的一项）
- 栏目：`【课标要求】【重点难点】【考情分析】` 等 **黑体 12pt 左对齐带【】**；
  「课前预习案／当堂检测／课后巩固案」这类**大栏目居中 15pt**
- 三级标题（知识点）：黑体 12pt 左对齐
- 页脚：居中「学案名　第 X 页（共 Y 页）」
- 一份完整学案 **2–4 页**（素材库里 25 份学案均在此区间）

## 二、栏目主线

素材中出现频次最高的栏目标签（括号内为出现次数）：

| 栏目 | 频次 | 作用 |
|---|---|---|
| 【课标要求】/【课程标准】 | 5+ | 开头必备，引自课标原文 |
| 【重点难点】 | 3+ | 各 1–2 条，用「重点：」「难点：」起句 |
| 【考情分析】 | 4 | 高考怎么考、几年几考 |
| 【时空定位】/【阶段特征】 | 3 / 3 | 文科（历史）专用，理科可换【知识框架】 |
| 【知识梳理】/【必备知识】 | 4 | 主干知识，填空式 |
| 【课前预习案】/【课前阅读区】 | 3 | 学生先学，必须留空 |
| 【学以致用】 | **20** | 例题/变式，出现最多 |
| 【课后巩固案】/【课后巩固提升】 | 4+ | 作业，3–6 题 |
| 【答案】/【解析】 | 34 / 24 | 答案版另附 |

**推荐顺序**（综合 6 份样本的栏目序列）：

```
学习目标（或课标要求）→ 重点难点 → 考情分析（可选）→ 知识梳理/课前预习
→ 课内探究（例题+变式）→ 当堂检测 → 课后作业 → 参考答案
```

## 三、写作要求（按真实学案的写作规律，不是格式清单）

1. **每个知识点以「学习聚焦」开头**——教材原句挖空，这是人教版学案的锚点：
   `学习聚焦：丝绸之路是经由中国____和____联通古代东西方的重要商路。`
   （新课学案必有；一轮复习学案换「阶段特征」段）
2. **课前预习必须填空**：关键概念、公式、结论挖空，密度约每页 6–10 处。
   Markdown 写 `{{加速度}}`，渲染成下划线空格（宽度自动 = 答案长度 + 2）。
   **答案版**（`make_xuean(answers=True)` 或 `jszz xuean --answers`）会额外出一份
   docx：答案以**红色压下划线**填回（真实答案版样式，红字不加粗），
   标题自动加「（答案版）」。
3. **四级嵌套编号是真实的写法**，别压平成一层：
   `1.概念：…` → `（1）背景：①…②…` → `1）对外输出：①…②…`
4. **「思考：」问题配多角度答案**——真实学案最爱的模式，答案按角度分点：
   ```
   思考：丝绸之路形成的因素
   ①政治：国家统一，政局稳定；②经济：经济繁荣，手工业技术先进；
   ③军事：北击匈奴保护商路安全；④个人：张骞通西域奠定基础；
   ⑤外部：丝路沿线国家参与。
   ```
   追问类还有「思考：如何理解……称为"凿空"？」→ ①一方面…②另一方面…
5. **对比表格**：张骞两次出使、时期/内容对照、输入/输出商品——真实学案每课 1–3 张表
6. **课后巩固 = 10+ 道高考真题选择题**，题源标在题号后：
   `1．（2025·云南高考·4）唐朝纺织品广泛应用了……` 结尾接 1 道材料题（13 分）
7. **材料题答案按点给分**：`【答案】（13分）` → 四个分点各 `（3分）`，末句总结
8. **探究例题**：`例1` 起头，题干给完整条件；`【解析】` 写清「取正方向 → 选公式 →
   代入 → 结论」；`【点睛】` 一句话点出方法要害；`【特别提醒】` 单独写**易错陷阱**
   （渲染成红条红底，课件里会变成独立一页）。一节课 2–3 个探究。
   题源写在题干前一行：`> 来源：（2025·山东济南一模）`

## 三·二、真实资料 vs AI 教辅的五个硬差异（788 份通读结论，照真实写）

1. **题源要溯源到页码**——真实写法粒度是「年份·地区卷别·题号」甚至教材页码：
   `（2025·山东高考·10）` `[2023·天津，16(3)]` `来源：人教A版必修第二册P202例3`
   `8.（2026年全国Ⅰ卷第8题）`。**绝不写**笼统的「高考真题」或编造「某地模拟」。
2. **评分标准是踩分合同，必须有负面边界**：
   `（答出"解放实践推动宣言演进"得2分，答"宣言推动解放"不得分）`
   `若只抄原文不翻译，此点0分` `三条均具备但未明确3人等次，扣1分`
   `（若从其他角度阐述合理，亦可酌情给分）`——只有正面要点的评分表是 AI 味。
3. **写进课堂运营痕迹**：`（5分钟）` `限时12分钟` `做题留痕，红笔改错`
   `整理今天课堂笔记到成长本` `会的 Pass，只背不会的` `字数要够！`
   `（答案用完收上来）` `1班……7班……`（分班差异）——纯学科内容是 AI 味。
4. **允许毛边与即兴**：同题给两稿答案（两个版本要点并存）、教师旁批
   `注：此题观察数值特殊性，有更简洁漂亮的解法！`、作文后附「Possible version」
   和问题清单 `problems: 1. so many "surprise"… 2. 第一段，Jeff和父亲是不能见面的`。
5. **方法指导类收尾要有动员语**：正文用「一、（一）1.」层级，结尾一段口号式收束
   `错题本记录的不是"这道题怎么做"，而是"我当时为什么想错"`
   `从现在开始，告别无效翻书，用这套系统方法吃透课本，筑牢基础、稳步提分`。

## 四、检测与答案

1. **当堂检测** 3–5 题，覆盖本节全部目标，最后一题略难。
2. **答案**：`---` 之后另起一页，按题号给答案；解答题给关键步骤，不只给结果。

## 五、学科差异（素材库实证）

- **历史**：栏目标签最多（课标要求/时空定位/阶段特征/重要历史概念/知识链接/拓展深化），
  预习部分是「时间轴 + 概念 + 填空」。
- **英语**：以「知识点 → 写作 → 话题评测 → 基础检测」四段式组织，一讲一测。
- **物理/化学/生物**：知识点 + 例题 + 变式的循环，公式推导要写清适用条件。
- **语文**：单篇精读，考点梳理 → 教考衔接 → 高考链接 → 一篇多练。

- [ ] 学习目标 3 条、动词开头
- [ ] 预习部分有 10 处以上填空
- [ ] 每个例题都有解析和点睛
- [ ] 当堂检测覆盖全部目标
- [ ] 有答案页、页脚有学校名
- [ ] 打印后不超 4 页（超了就把「知识链接/拓展深化」砍掉）
