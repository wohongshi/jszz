# 图片引用规范（788 份真实资料的图注统计 + 网络找图）

> 统计口径：全库文本 405 万字中一切「图 N」「如图」「据此完成」的引用形态。
> 图片本身从网络找（`tools/webimg.py`），但**引用写法必须照真实资料**。

## 一、图注句式（图 N 后面跟什么，实测频次）

| 句式 | 频次 | 真句 |
|---|---|---|
| 图N**示意**… | 28 | `图12示意该地区晚全新世以来古湖泊到沼泽湿地的演变模式` |
| 图N**为**… | 26 | `图2为1867—1897年日本国内各类棉布需求量的变化示意图` |
| 图N**所示** | 15 | `图2所示`（正文指代时） |
| 图N**是**… | 13 | `图4是1953年创作的年画` |

**配套要素**：

- **单位括注**：`图5示意1984—2006年该平原地下水位下降深度等值线（单位：m）`
- **一图一注**，多图并列各自编号：`图9示意瑙鲁地理位置，图10为瑙鲁光伏发电项目景观`
- **美术/文物图注录式**（语文、历史）：`图5 《工人新村》（1952年，孙佳桐 何正慈作）`
  ——作品名 +（年代，作者）；`图5为1808年欧洲的一幅时事漫画，名为《蛛网里的科西嘉…》`
- **编号连续**：图1、图2…按出现顺序，跨页不重排

## 二、正文指代词（不是都叫「如图」）

| 指代词 | 频次 | 用法 |
|---|---|---|
| 如图/下图/右图/左图 | 1962 | 位置指代：`速率和H2起始浓度呈如图所示的直线关系` |
| 据图/图中/图示 | 988 | 内容指代：`据图判断…`、`图中①②⑨表示该保护区的三种功能区` |
| 图N+所示 | 15 | 精确指代（一文多图时必须用这个，不能说「如图」） |

**一文多图时禁止裸「如图」**——必须「图N所示/据图N」，否则学生不知道指哪张
（真实资料里一文多图全部用「图N」精确指代）。

## 三、组题锚点（一图多题，174 处，地理占 134）

```
图2示意基多水基金项目所在流域概况，据此完成5~7题。
```

- 「**据此完成N~M题**」紧跟图注之后、题干之前——一组题共享一图
- 选择题组每题不再重复贴图；综合题则「材料—图—设问」三层
- 题号连续：`据此完成5~7题` 后接 `5.` `6.` `7.`

## 四、写作模板（jszz 生成时照此写）

**试卷/学案（docx）**：

```markdown
![图1示意热力环流的形成过程（单位：hPa）](/path/to/img.jpg)

1. 据图1所示，近地面风向为（　　）
…
3. 图1示意的环流中，市区气温高于郊区的原因是？（6分）
```

**课件（pptx）**：`![图注](path)` 的 alt 就是图注，渲染在图下方灰字居中。

**一图多题**：

```markdown
![图2示意基多水基金项目所在流域概况](/path/to/valley.jpg)
> 据此完成 1~3 题。
```

**历史/语文的美术图**：

```markdown
![图5 《工人新村》（1952年，孙佳桐 何正慈作）](/path/to/painting.jpg)
```

## 五、网络找图（tools/webimg.py）

```bash
python3 tools/webimg.py search "热力环流示意图" --count 6   # 必应图搜（主力，直连）
python3 tools/webimg.py search "thermal circulation" --source commons  # Wikimedia（走代理，CC 授权）
python3 tools/webimg.py download "<图URL>" --title "…" --query "…"     # 下载入库
```

- 下载落 `~/.jszz/assets/web/<hash>.<ext>`，**来源 URL + 检索词记入 index.jsonl**（署名溯源）
- 命中率实测：搜「热力环流示意图」前三条全是真教学示意图（新浪/21cnjy/教习网）
- **图片版权**：百度图搜反爬（Forbid spider），已弃用；Wikimedia 的图自带
  CC 授权与作者信息，公开出版物优先用它；课堂内部使用的图标注「来源：网络」即可
