# 课件规范（来自 318 份真实 PPT 的统计）

> 六科各一套视觉语言（封面/页头/装饰/专属页型）见 `09-六科课件视觉.md`；
> 本篇是跨学科通用的通则。

## 一、硬指标（实测中位数）

| 指标 | 数值 |
|---|---|
| 画幅 | 16:9（13.333 × 7.5 英寸），96% 的课件如此 |
| 页数 | 33 页（中位数），一节 40 分钟课约 25–35 页 |
| 每页字数 | 184 字（中位数）→ 超过 300 字就该拆页 |
| 每页图片 | 0.61 张（中位数）→ 平均两页一张图 |
| 正文字号 | 28pt 最多（其次 24 / 26pt） |
| 标题字号 | 32pt 以上（40–44pt 常见） |
| 中文字体 | 微软雅黑（第一）、黑体、楷体、宋体 |
| 西文字体 | Times New Roman（数字/公式必备） |

## 二、页面叙事（素材库里的固定套路）

页面标题高频词（出现次数）：

```
关键能力•练透考法 79      必备知识•精读教材 57      思维建模 41
素养提升 33              科学思维•教考衔接 30      学以致用 24
目录 23                  考点一/考点二…           高考链接 18
课时精练 18              知识诊断自测 14          考点聚焦突破 14
```

**新授课**：封面 → 学习目标 → 情境导入 → 知识点 1（讲）→ 例 1（题干页）→ 解析 →
变式 → 知识点 2 … → 当堂检测 → 小结 → 作业

**复习课**：封面 → 课标解读/考情 → 知识框架 → 考点一（必备知识 + 关键能力 + 真题）→
考点二 … → 易错清零 → 课时精练

**讲评课**：封面 → 成绩/错题分布 → 逐题（题干页留白 → 答案页）→ 变式补偿 → 小结

## 二·五、三色分工（从物理一轮复习课件逐页拆出来的规则）

| 颜色 | 角色 | 用途 |
|---|---|---|
| 深海军蓝 `#0F2B55` | 结构色 | 页头、封面右块、竖排书脊、表格表头 |
| 青蓝 `#2E86D6` | 连接色 | 顶部细线、底部色带、chip、序号块、项目符号 |
| 警示红 `#C81E1E` | 风险色 | **只用于易错/高频**：特别提醒、判定要点、`【标签】` |

> 最重要的一条：**红色不是装饰，是「这里容易错」的标记**。真实课件里红色只出现在
> 特别提醒、高频考点、例题批注三处；满屏红色等于没有红色。

## 三、版式规则（jszz 已内置）

- **两套页头**：栏目式（顶部细线+左侧竖条+标题，用于目标/考情/小结）与
  通栏式（深蓝色块通栏+白字标题+右上 chip，用于考点/知识点/例题/答案）
- 封面：左侧白底标题（自动在「（」前断行，字号按最长行算），右侧深蓝块放金色讲次
- 底部通栏色带 + 页脚「学校 · 课题 | 页码」
- 正文左对齐，项目符号 ▪，悬挂缩进 0.55cm，行距 1.35
- 例题页：蓝「例N」序号块 + 题源小字 + 题干 + 选项网格 + **右侧红框「判定要点」**
  （判定要点来自 `【点睛】/【点评】`，一句话一条，最多 3 条）
- 答案页：绿色竖条 + 答案 22pt（长答案自动降 19/16pt）+ 解析 18–20pt
- 页脚左「学校 · 课题」，右页码，10pt 浅灰
- 封面标题按长度自适应 24–40pt，避免长标题折成孤字

## 四、按学科的风格差异

| 学科 | 风格 |
|---|---|
| 物理/化学 | 公式多、图示多，每页一张图；例题必须给「已知/求/解」三段 |
| 生物 | 概念图 + 表格对比，颜色区分「结构/功能」 |
| 历史 | 时间轴 + 史料原文 + 结论，一页一则材料 |
| 政治 | 「情境 → 设问 → 知识 → 答案」四段式 |
| 语文 | 原文片段 + 批注，字号可到 28pt，一页一段 |
| 英语 | 例句 + 语法框，中英混排，英文用 Times New Roman |

## 五、自检清单

- [ ] 封面有课题、学段学科、授课人/学校
- [ ] 每页不超过 6 条、300 字
- [ ] 例题都是「题干页 + 解析页」两页
- [ ] 没有 `{{}}`、`【】` 之外的标记残留（渲染器会把 `【】` 变强调色）
- [ ] 没有空页；页码连续
- [ ] 用 16:9，投影不裁边（左右各留 0.6 英寸安全区）
