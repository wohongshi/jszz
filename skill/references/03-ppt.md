# 课件规范（来自 318 份真实 PPT 的统计）

> 六科各一套视觉语言（封面/页头/装饰/专属页型）见 `09-六科课件视觉.md`；
> 本篇是跨学科通用的通则。

## 一、硬指标（实测中位数）

| 指标 | 数值 |
|---|---|
| 画幅 | 16:9（13.333 × 7.5 英寸），96% 的课件如此 |
| 页数 | 33 页（中位数），一节 40 分钟课约 25–35 页 |
| 每页字数 | 184 字（中位数）→ 超过 300 字就该拆页 |
| 每页图片 | 0.61 张（中位数）→ 平均两页一张图 |
| 正文字号 | 28pt 最多（其次 24 / 26pt） |
| 标题字号 | 32pt 以上（40–44pt 常见） |
| 中文字体 | 微软雅黑（第一）、黑体、楷体、宋体 |
| 西文字体 | Times New Roman（数字/公式必备） |

## 二、页面叙事（素材库里的固定套路）

页面标题高频词（出现次数）：

```
关键能力•练透考法 79      必备知识•精读教材 57      思维建模 41
素养提升 33              科学思维•教考衔接 30      学以致用 24
目录 23                  考点一/考点二…           高考链接 18
课时精练 18              知识诊断自测 14          考点聚焦突破 14
```

**新授课**：封面 → 学习目标 → 情境导入 → 知识点 1（讲）→ 例 1（题干页）→ 解析 →
变式 → 知识点 2 … → 当堂检测 → 小结 → 作业

**复习课**：封面 → 课标解读/考情 → 知识框架 → 考点一（必备知识 + 关键能力 + 真题）→
考点二 … → 易错清零 → 课时精练

**讲评课**：封面 → 成绩/错题分布 → 逐题（题干页留白 → 答案页）→ 变式补偿 → 小结

## 二·六、PPT 页型与栏目词表（18 份真实课件逐页统计）

**通用页型序列**（每科真实课件都走这条线）：

```
封面 → 目标要求（1–3 条编号）→ 内容索引/考点导航 → 考点N（章节页）→
知识点讲解页 → 例题页（题源+题干+选项）→ 解析页 → 检测/实战 → 归纳总结
```

**真实栏目词**（照抄别自创，18 份课件实测出现的）：

| 学科 | 栏目词 |
|---|---|
| 通用 | 目标要求 · 内容索引 · 考点一/二/三 · 知识拓展 · 归纳总结 · 实战训练 |
| 物理/化学 | 原理及装置图 · 实验思路 · 数据处理 · 注意事项 · 误差分析 · 疑难解析 |
| 数学 | 回忆与展望 · 合作探究 · 思考 · 当堂检测 |
| 语文/英语 | 课前背记 · 词汇整理 · 句式结构 · 核心词块 · 话题微写作 · Task 1–5 |
| 历史/政治 | 课程标准 · 读图观变 · 精讲核心考点 · 旁栏思考 · 探究·实践 |
| 生物 | 要点回顾 · 实战训练 · 旁栏思考（P80）· 探究·实践 |

**每页密度**（实测均值）：正文 100–200 字/页（语文早读 237、英语写作 638 是特例）；
形状 2–9 个/页（生物背诵 33 是特例——填空极密）；图 0.5–2 张/页。

**真题页写法**：题源 `（2024·河北卷·11）` 打头 → 题干 → 选项 → （下一题页）答案+解析。
物理实验课的「数据处理/注意事项/误差分析」三页固定按 (1)(2) 分条。

| 颜色 | 角色 | 用途 |
|---|---|---|
| 学科主色（各科不同） | 结构色 | 页头、封面标题、表格表头、章节页 |
| 学科强调色 | 连接色 | 细线、chip、序号块、项目符号、解析标签 |
| 警示红 `#C00000` | 语义色 | **答案 / 例N 标签 / 纠错 / 易错**——六科通吃 |
| 黄 `#FFE699` | 高亮 | Learning aims、必背、篇目标签 |

> 最重要的一条：**红色在真实课件里就是「答案 + 这里容易错」的标记**（17/17 一致），
> 满屏红色等于没有红色；答案一律红色，不再用绿色。

## 三、版式规则（jszz 已内置）

- **两套页头**：栏目式（各科形态不同：语文提示横条 / 数学细线框 / 英语青色【栏目】块 /
  化学蓝胶囊 / 生物绿块；用于目标/考情/小结）与例题页式（白底 + 红标签 + 细线，
  用于考点/知识点/例题/答案——真实课件的例题页没有深色通栏）
- 封面六式按学科取证（见 09）：语文信息栏 / 数学标题牌+标签组 / 英语 Learning aims /
  物理轨道弧线 / 化学试管卡片 / 生物放射概念图
- 页脚「学校 · 课题 | 页码」；物理/化学另有页码方块导航（‹ N ›）
- 正文左对齐，项目符号 ▪，悬挂缩进 0.55cm，行距 1.35
- 例题页：红「例N」标签 + 题源小字 + 题干 + 选项网格（按格宽 4→2→1 列）+ **右侧红框「判定要点」**
  （判定要点来自 `【点睛】/【点评】`，一句话一条，最多 3 条）
- 答案页：蓝「解析」标签 + 红色答案 22pt（长答案自动降 19/16pt）+ 解析 18–20pt
- 页脚左「学校 · 课题」，右页码，10pt 浅灰
- 封面标题按长度自适应 20–42pt，避免长标题折成孤字

## 四、按学科的风格差异

| 学科 | 风格 |
|---|---|
| 物理/化学 | 公式多、图示多，每页一张图；例题必须给「已知/求/解」三段 |
| 生物 | 概念图 + 表格对比，颜色区分「结构/功能」 |
| 历史 | 时间轴 + 史料原文 + 结论，一页一则材料 |
| 政治 | 「情境 → 设问 → 知识 → 答案」四段式 |
| 语文 | 原文片段 + 批注，字号可到 28pt，一页一段 |
| 英语 | 例句 + 语法框，中英混排，英文用 Times New Roman |

## 五、自检清单

- [ ] 封面有课题、学段学科、授课人/学校
- [ ] 每页不超过 6 条、300 字
- [ ] 例题都是「题干页 + 解析页」两页
- [ ] 没有 `{{}}`、`【】` 之外的标记残留（渲染器会把 `【】` 变强调色）
- [ ] 没有空页；页码连续
- [ ] 用 16:9，投影不裁边（左右各留 0.6 英寸安全区）
