# 九科学案模板（照 U 盘真实学案逆向出来的）

> 来源：语文《师说》一轮复习学案、数学导数单元卷、英语话题 1 四件套、物理第 02 讲、
> 化学作业 1–7 答案、生物寒假自主学习 1–14、历史纲要上第 2/11 课学案、
> 政治必修四单元复习、地理热力环流与讲评卷。每科的栏目顺序都是这些文件里实际出现的，
> 不是通用教育学模板。

## 共通骨架（先满足这 6 条，再谈学科差异）

1. **抬头**：`胶州四中一轮复习（X科）学案　编号：__`｜页眉右「编写人／审核／时间」
2. **学习目标**：1–3 条，动词开头（理解/掌握/会/能），每条 ≤ 40 字
3. **知识梳理必留白**：`{{答案}}` 挖空，或判断题「( )」——纯讲义不算学案
4. **例题带出处**：`> 来源：（2025·山东卷·3）`，解析写到选项级
5. **当堂检测 3–5 题** + **课后作业**
6. **答案页**：`---` 另起，`## 参考答案`

## 三、英语（一话题四件套）

一讲拆成 4 份，编号连续（No.1 → No.5）：

| 份 | 名称 | 内容配额 |
|---|---|---|
| No.1 | 知识点 | 单句语法填空 20 + 改写句子 5 + 翻译 3 |
| No.2 | 写作 | 朗读英译汉 → 汉译英 → Task1 梯度写作（Para.1/3 各两版范文）→ Task2 读后续写微写作 |
| No.3 | 话题评测题 | 4 篇阅读 + 1 篇七选五，逐题标「细节理解/推理判断/主旨大意」 |
| No.4/5 | 基础检测案 | 单词拼写 10（★核心/☆高频）+ 词性转换 10 + 句型 + 写作 |

```markdown
# 高三英语一轮复习 话题1 学校及家庭生活 No.4 基础检测
> 学科：英语 | 年级：高三 | 编号：No.4

## 一、单词拼写（每空1分，共10分）
根据句意及汉语提示写出单词（★核心 /☆高频）
1. The first day at senior high left a deep ____ (印象) on me.
…

## 二、词性转换（每空1分，共10分）
curious → ____ (n.)　impress → ____ (n.)

## 三、句型转换 / 四、写作任务
```

**要点**：英语学案不写「知识框架」，写**题量配额**；每个话题固定 4 份，
学生按编号推进。读后续写单独出学案：文本分析 → conflicts → clues → 结局 → 十句五定。

## 六、生物（章末填空案 / 复习学案）

### 填空案（假期自主学习形态，14 份连发）
```markdown
# 高二生物寒假自主学习（2）
## 第二节 微生物的基本培养技术及应用
### 一、微生物的基本培养技术
1. 微生物的定义：肉眼难以看清，需要借助光学显微镜…的 {{一切微小生物}} 的总称。
（3）培养基类型：按物理状态可分为 {{液体培养基}} 和 {{固体培养基}} 。
（3）无菌技术：①对操作的 {{空间}}、操作者的 {{衣着}} 和 {{手}} 进行 {{清洁}} 和 {{消毒}}；
```
一份 2 000–2 500 字，编号知识点连续，**答案直接嵌在空里**（答案版），
学生版把 `{{}}` 留空即可。

### 复习学案（栏目化）
```markdown
# 第4讲 细胞膜与细胞核
## 必备知识•精读教材
（教材原句）台盼蓝染液不能将活细胞染色，原因是活细胞的细胞膜 {{具有选择透过性}} 。

## 科学思维•教考衔接
（2026·重庆模拟）缝隙连接…
## 关键能力•练透考法
## 归纳拓展（五种常考膜蛋白及其功能）
```

**要点**：生物的栏目名就是它的教学法——「精读教材 → 教考衔接 → 练透考法 → 归纳拓展」，
四栏缺一不可；教材原句挖空是最有价值的题型（高考逐年回归教材）。

## 七、历史（一课一案，时空定位打头）

```markdown
# 第9课　古代的商路、贸易与文化交流
> 学科：历史 | 年级：高二 | 编写：李晓 | 审核：高二历史组 | 时间：2026.3.7

## 【课标要求】     ← 引课标原文
## 【重点难点】     ← 各 1–2 条，「重点：」「难点：」起句
## 【时空定位】     ← 时期/大事 两列表（西汉/唐代/宋元/明清）
## 【重要概念解析】 ← 词条式：名称 + 解释（"一带一路"是…）
## 【课前预习案】
### 知识点一：丝绸之路      ← 学习聚焦：…{{挖空}}…
## 【学以致用】             ← 10+ 道高考真题，题源（2025·云南高考·4）
## 【课后巩固案】
## 【参考答案】            ← 材料题按点给分（13分）
```

**要点**：历史学案必有**时空定位表**和**重要概念解析**（其他科没有）；史料题先给材料再设问，
材料末尾挂出处`（节选自吕本中《官箴》）`；答案按要点给分，末句回扣主题。

**历史 Word 语料实测（34 份 / 106 条）补充**：

- **课前阅读区**：`故事/细节：……` 起笔（约 300 字）→ 末尾 `对应知识点：商业革命与货币金融`
- **重要概念**词条化：`1.玄学：魏晋南朝流行的社会思潮`，先定义后外延，每条约 200 字
- **阶段特征**按政治/经济/思想文化/民族对外分面写，先总后分
- **选择题解析套式**：`【答案】B【解析】据材料……，故选B项`；
  错误项逐一给硬理由并固定收尾 `排除A项`，错因定性为不合材料/不合史实/因果倒置/表述不当
- **大题答案**：要点式短句、动词开头、分号并列；先给评分要点再附成文范文（两遍式）
- **负面边界**（历史卷的命门）：`作用与史实不对应的不得分`、`答"宣言推动解放"不得分`、
  `（只写亚洲不得分）`、`梁错别字扣1分`、`上位词不给分`
- **小论文**：论题（一句话判断句）→ 阐述（按时间线索串史实）→ `总之，……` 回扣论题
- **官答分轨**：官答用【官答】【官解】，自拟答案标 `（非官答）`
- **教师用卷**留下载戳：`胶州四中20260918高三级年级下载试题`
- **易错提醒**直写失分口径：`答"地理决定论"会失分`、`易错提醒 · 万民法≠人人平等`

## 八、政治（一单元一案，知识建构 + 命题分析）

```markdown
# 必修三 第5课　人民代表大会制度
> 学科：政治 | 年级：高二

## 【课标要求】（限时 8 分钟完成，做题留痕，红笔改错）
## 【重点难点】
## 【知识建构】     ← 概念对比表：概念 / 性质 / 常考陷阱（"不是…"必写）
## 【简记】         ← 口诀：「一主两大三职四权」
## 【课前背记】     ← 挖空填空
## 【命题分析】     ← 视角 / 本题特点 / 历年对照（2025·山东高考·10）
## 【学以致用】     ← 选择题 + 14 分材料题，答案含负面边界
## 【课后巩固】
```

**要点**：政治必写**常考陷阱列**（「公民」≠「人民」，混淆即失分）；主观题答案带
**负面边界**（`若只抄原文不翻译，此点 0 分`）；时政题材料挂出处。

**政治 PPT 语料实测（19 份全读）修正**：

- **栏目名一律「四字·四字」对仗**：命题透视·考情前瞻、体系构建·思维导图、
  核心突破·重难全析、解题赋能·素养提升、思维建模·脉络梳理、知识解构、考向破译
- **一轮复习五段式**：命题透视·考情前瞻（三维考情表：核心考点 × 年份 × 卷别题号 × 分值）
  → 体系构建·思维导图 → 核心突破·重难全析（每考点 = 知识点表格 内容/区别/联系
  + 考向洞察 真题/答案/排除式解析）→ 归纳总结 → 解题赋能·素养提升
- **讲评类首页**：选择题答案串每 5 个字母一组空格分隔 `BCDBA / ADCBA / DACCB / BBCB`，
  或用「题号—答案」两行对照表
- **主观题答案**：【答案】起头 → ①②③分条，每条固定「教材原理句 + 材料对接句」；
  【原理】【方法论】成对书写；先世界观后方法论、先原理后材料
- **演绎推理三步**：判定推理类型 → 引用逻辑规则 → 指出错误名称（`犯了"大项不当扩大"的错误`）
- **替代得分显式标注**：`（供给侧结构性改革替代得分2分）`
- **评分四级拆解**：总分 → 角度 → 要点 → 每点分值；普遍带 `不重复给分` 约束；
  降级给分（`只答扩大消费给1分`）；负面边界写出「不给分」并说明原因
- **题源前置括号**：`（2026·山东·高考真题）`、`（2025·山东东营·二模）`、
  可带学段 `（2025高二·全国·专题练习）`、可带小题号分值 `（2023江苏，13，3分）`
- **法条/教材溯源**：法条链接精确到条款项（《民法典》第五百九十条第二款）、教材页码 P26/P47
- **课堂运营**：上课要求三条（禁止/勤快/思考）、集错本每周收一次批改、
  学生姓名挂题后（典题由学生讲）、口诀（`热紧紧、冷扩扩`；`全真则真，一假则假`）、
  讲评首页励志标语
- **易错清单用判断题 + 「纠正：」句式**（政治独有的边界写法）：
  `1. 人类进入奴隶社会，私有制确立、国家产生。纠正：私有制确立于原始社会末期…`
- **学生问题四条**（讲评标配失分清单）：审题不准答非所问 / 术语口语化 /
  不分条列点知识点后置 / 书写潦草卷面杂乱；短评设问带四条要求
  （`①围绕主题，观点明确…④总字数在250字左右`）

## 九、地理（专题一案，目标分解 + 评分标准）

```markdown
# 专题11　热力环流与大气的水平运动
> 学科：地理 | 年级：高三

## 【课标要求】（限时 12 分钟，先画图再答题）
## 【重点难点】
## 【目标具体分解一/二/三】   ← 地理独有，逐个目标拆开
## 【知识梳理】               ← 环节 / 过程 / 结果 三列表
## 【方法技巧】               ← 判读三步法 + 【特别提醒】
## 【学以致用】
## 【评分标准】               ← 要点 / 分值 / 负面边界 三列表（地理独有）
## 【课后巩固区】
```

**要点**：「目标具体分解一/二/三」和「评分标准表」是地理独有；读图题先写
**方法步骤**再答题；`课后巩固区` 而非「课后巩固」。

**地理 PPT 语料实测（26 份全读）修正**：

- **一轮复习八段式**（约 16/24 份）：封面（届次+学校+教研组+编号+课题，如
  `编号15 高考复习 水循环和陆地水体间的相互关系`）→ 考情分析·考点提取
  （左课标原文 + 核心素养目标逐条编号 1.综合思维 2.区域认知 3.地理实践力，
  右「核心考点—地区—命题方向」三年真题表）→ 命题透视·考情前瞻 →
  思维建模·脉络梳理 → **知识解构·考向破译**（篇幅主体：考点一/二/三 → 知识点
  01/02/03，重难标「（重点）」→ 表格「因素—影响/类型—特点—典例」→ 考向 01/02/03
  → 典例 `（2026·云南卷）` + 类题巩固 `（2026·河南·模拟预测）`）→ 拓展/概念辨析 →
  课堂巩固区/课后巩固区（典型例题+变式训练+反馈练习，综合题带分值 `（21分）`）
  → 收尾（单元逻辑图 / 谢谢观看）
- **微专题课型**（地理独有）：封面「微专题1 地质过程描述」，随后 5 道同构题
  （`描述／说明／简述…的形成过程`）刷过程描述模板，只换情境不换设问
- **过程描述答案 = 严格时序因果链**，一步一句首尾相接：
  `①地壳相对稳定期间，河流以侧蚀和堆积为主，形成宽广的河漫滩；②地壳抬升，河床
  比降加大，水流下切，原河漫滩成为阶地；③地壳多次间歇性上升，形成多级阶地`
- **因果式短句三件套**：`条件/因素 + 机制 + 结果`（机制必写）：
  `地处背风坡风力较弱，便于沉积；坡度较缓，易于沉积；降水较少，流水侵蚀较弱`
- **对比/异同类**：先相同点再不同点，另起「不同点成因：」
- **开放性设问双立场**：`赞同。①…②…③…` / `不赞同。①…②…③…` 各列 3–4 条
- **答案条数 = 分值**（6分≈3点，8分≈4点）；先给结论词（`位置：丙处。`）再展开；
  材料与答案严格对应，位置用图中标注词（`甲地/凹岸/凸岸/上游/下游`）
- **讲评类只给裸答案**：答案速查表两行（`题号 1 2 3…` / `答案 C B A…`），
  选择题不写解析（`C/B/D`），个别题才用「分析图文材料可知……综上所述……故 B 正确」
- **术语教材化禁口语**：固结成岩/重熔再生/溯源侵蚀/冲淤平衡/削峰补枯/顶托作用/凌汛
- **题源**：`（2026·云南卷）` `（2025·山东）` `（2026·河南·模拟预测）`；
  日常管理页是日期清单（`今晚（5.14）地理作业：①完成编号2全部（明天收）`）
