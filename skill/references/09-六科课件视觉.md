## 自动选型

`make_xuean` / `build_xuean_deck` 读 Markdown 里的 `> 学科：物理`，自动套对应风格；
也接受显式 `theme=`（`chinese|math|english|physics|chemistry|biology|general`）。
讲评课件（`build_paper_deck`）同样跟随学科。

```python
build_xuean_deck(md, out, school="胶州四中")            # 自动按 学科 选
build_xuean_deck(md, out, theme="chemistry")            # 显式覆盖
```

## 专属页型：写在 Markdown 里

各科有「别的学科没有」的页面，用一行指令触发（放在对应 `##` 小节内）：

```markdown
> 引文：师者，所以传道受业解惑也。……道之所存，师之所存也。（节选）——韩愈《师说》
> 公式：v = v₀ + at | 条件：匀变速直线运动 | 结论：已知 v₀、a、t 求末速度
> 对照：He turned his head toward the door. | 他转头看向门口。
> 反应：2H₂(g) + O₂(g) = 2H₂O(l) | 条件：点燃 | 放热反应，ΔH = −571.6 kJ·mol⁻¹
> 概念：细胞膜 > 结构：磷脂双分子层;蛋白质 > 功能：控制物质进出;信息交流
```

| 指令 | 版式 | 适合学科 |
|---|---|---|
| `引文` | 大段原文 + 出处落款 | 语文、历史 |
| `公式` | 公式卡 + 条件/结论两栏 | 数学、物理、化学 |
| `对照` | 左右两栏（英/中），可挂词块 | 英语、生物（双语材料） |
| `反应` | 方程式卡 + 条件标签 + 要点 | 化学 |
| `概念` | 中心词 + 分支卡片 | 生物、政治、地理 |

## 字体与兜底

- 语文正文 **楷体**、标题黑体；数学/物理/化学 **宋体**（西文 Times New Roman，
  公式可 Cambria Math）；英语/生物 **微软雅黑**——与真实课件的字体统计一致。
- 生成时检测本机字体：缺字形按类退（宋/楷 → Noto Serif CJK SC，
  黑/雅黑 → Noto Sans CJK SC），老师 Windows 上仍用原字体。

## 每科的内容节奏（写 Markdown 时就按这个排）

| 学科 | 一节课的页面顺序 |
|---|---|
| 语文 | 封面 → 学习目标 → 字词 → 活用 → 句式（引文页）→ 检测 → 答案 |
| 数学 | 封面 → 学习目标 → 知识诊断 → 常用结论（公式页×N）→ 考点例题+解析 → 精练 → 答案 |
| 英语 | 封面（Learning aims）→ 单词拼写 → 词性转换 → 微写作（对照页）→ 话题评测 → 答案 |
| 物理 | 封面 → 目标 → 考情表 → 知识点 → 公式页×N → 考向例题（红例N+判定要点）→ 精练 → 答案 |
| 化学 | 封面 → 目标 → 考点（反应式页）→ 易错辨析（√/×）→ 真题 → 答案 |
| 生物 | 封面 → 精读教材（概念图）→ 教考衔接 → 练透考法 → 归纳拓展 → 答案 |

## 关键实现约束（踩过的坑）

- 竖排文本（`vert="eaVert"`）在 LibreOffice 里裁字——所有竖排标签改横排
- 浮点 EMU 坐标会让 python-pptx 崩（`add_connector` 必须传 int）
- 装饰图形一律画在页面内（负坐标/出血会被 QA 报越界）
- kicker 与标题互为子串时去重，避免「考点二 xxx」标两次
- 物理/化学的 closing 页走 `_chrome()` 统一页脚，避免双行页脚叠印
- 例题选项按格宽反推列数（4→2→1），绝不把「偶函数」拆成「偶函/数」
