## 自动选型

```python
build_xuean_deck(md, out, school="胶州四中")            # 自动按 学科 选
build_xuean_deck(md, out, theme="chemistry")            # 显式覆盖
```

## 专属页型：写在 Markdown 里

各科有「别的学科没有」的页面，用一行指令触发（放在对应 `##` 小节内）：

```markdown
> 引文：师者，所以传道受业解惑也。……道之所存，师之所存也。（节选）——韩愈《师说》
> 公式：v = v₀ + at | 条件：匀变速直线运动 | 结论：已知 v₀、a、t 求末速度
> 对照：He turned his head toward the door. | 他转头看向门口。
> 反应：2H₂(g) + O₂(g) = 2H₂O(l) | 条件：点燃 | 放热反应，ΔH = −571.6 kJ·mol⁻¹
> 概念：细胞膜 > 结构：磷脂双分子层;蛋白质 > 功能：控制物质进出;信息交流
```

对应产出：

| 指令 | 版式 | 适合学科 |
|---|---|---|
| `引文` | 大段原文居中 + 出处落款 | 语文、历史 |
| `公式` | 公式居中大字 + 条件/结论两栏 | 数学、物理、化学 |
| `对照` | 左右两栏（英/中），可挂词块 | 英语、生物（双语材料） |
| `反应` | 方程式 + 条件标签 + 要点 | 化学 |
| `概念` | 中心词 + 分支卡片（2×4） | 生物、政治、地理 |

## 字体与兜底

- 语文正文/标题用 **宋体**（衬线），其余五科用 **微软雅黑**（黑体）。
- 生成时检测本机字体：没有宋体就退到 `Noto Serif CJK SC`，没有雅黑就退 `Noto Sans CJK SC`，
  保证在 Linux/服务器上渲染不塌；老师的 Windows 机器上仍然用宋体/雅黑。

## 每科的内容节奏（写 Markdown 时就按这个排）

| 学科 | 一节课的页面顺序 |
|---|---|
| 语文 | 封面 → 学习目标 → 字词 → 活用 → 句式（引文页）→ 结构（概念图）→ 检测 → 答案 |
| 数学 | 封面 → 学习目标 → 知识诊断 → 常用结论（公式页×N）→ 考点一/二（例题+解析）→ 精练 → 答案 |
| 英语 | 封面 → 学习目标 → 单词拼写 → 词性转换 → 微写作（对照页）→ 话题评测 → 答案 |
| 物理 | 封面 → 目标 → 考情表 → 知识点 → 公式页×N → 考向例题 → 特别提醒 → 精练 → 答案 |
| 化学 | 封面 → 目标 → 考点（反应式页）→ 知识点（公式页）→ 真题 → 答案 |
| 生物 | 封面 → 精读教材（概念图）→ 教考衔接 → 练透考法 → 归纳拓展 → 答案 |
