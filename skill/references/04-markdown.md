# jszz Markdown 语法（学案 / 试卷 / 课件共用）

渲染器只认这套子集，多余的 Markdown 会被当成普通段落。

## 1. 结构

| 写法 | 学案 | 试卷 | PPT |
|---|---|---|---|
| `# 标题` | 封面标题 | 试卷标题 | 封面标题 |
| `> 学科：物理 \| 年级：高一 \| 课时：1` | 副标题元信息 | `> 时间：90分钟 \| 满分：100分` | 封面副标题 |
| `## 栏目` | 【课前预习】等栏目，带分隔线 | 大题标题（一、单项选择题…） | 一页（超长自动续页） |
| `### 知识点` | 三级标题 | 少用 | 一页 |
| `---` | 分页（答案另起） | 分页 | 新章节 |

元信息的键名会影响排版（一行可写多组，用 `|` 分隔）：

- 学案：`学科 年级 课 课时 编写 审核 时间` → 页眉右侧自动排「编写人／审核／时间」
- 试卷：`时间 满分 日期` → 标题与日期同行，下面一行 `（时间：90分钟　满分：100分）`
- `说明：…` 可替代默认的分值说明行
`> 密封线：否` 可关掉班级/姓名/考号三栏。

## 2. 正文元素

```markdown
- 无序要点（学案里的目标、作业）
1. 有序条目（预习知识点、题目）
A. 选项（四个一行写成 `A. 甲　B. 乙　C. 丙　D. 丁` 会自动排四列）
{{加速度}}          挖空：docx 变下划线空格，ppt 变下划线
【解析】…           解析块：docx 灰条灰底；PPT 变「答案页」
【点睛】…           方法要点：docx 蓝条蓝底；PPT 变例题右侧「判定要点」
【特别提醒】…       易错陷阱：docx 红条红底；PPT 单独成页（红色警示）
| 列1 | 列2 |     表格（第一行表头）
![图注](图片路径)   图片，宽 9cm 居中
> 来源：2026 山东卷第 8 题   题源（PPT 显示在序号块右侧，docx 小灰字）
```

## 3. 例题的标准写法

```markdown
### 探究一：刹车类问题中的「时间陷阱」

例1　汽车以 20 m/s 行驶，刹车加速度大小为 5 m/s²。求：
（1）2 s 末的速度；
（2）6 s 内的位移。

【解析】（1）取初速方向为正，a＝－5 m/s²，v＝v0＋at＝10 m/s。
（2）刹车时间 t0＝4 s＜6 s，故 x＝v0t0/2＝40 m。

【点睛】刹车问题先求停止时间，再判断所给时间是否超时。
```

渲染结果：PPT 自动出「例1 题干页」+「例1 解析页」；docx 连排。

## 4. 试卷的题目写法

```markdown
## 一、单项选择题：本题共8小题，每小题3分，共24分

1. 关于匀变速直线运动，下列说法正确的是（　　）

A. 速度随时间均匀变化　B. 加速度随时间均匀变化　C. 位移随时间均匀变化　D. 加速度方向与速度方向一定相同

2. ……

## 三、非选择题：本题共4小题，共60分

6. （12分）一物体从静止开始……

（1）3 s 末的速度；

---

## 参考答案

1. A
6. 【答案】6 m/s 【解析】v＝at＝2×3＝6 m/s
```

要点：
- 题号用 `1.` `2.`，不要用 `1、`（也能识别，但统一更好）
- 选项**四个一行**写，渲染器自动 4 列；太长自动 2×2
- 分值写在题干开头 `（12分）`
- 答案页用 `---` 隔开，`## 参考答案` 开头

## 5. 学案的填空写法

```markdown
1. 定义：物体沿一条直线运动，且{{加速度}}不变的运动叫匀变速直线运动。
2. 速度公式：v＝{{v0＋at}}。
```

`{{}}` 里写答案，渲染时变成下划线空格（宽度 = 答案长度 + 2 个汉字）。
答案版可以另存一份把 `{{}}` 换成正文。

## 6. 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| `## 一、选择题` 后面不写分值 | 试卷看不出配分 | 写「本题共8小题，每小题3分，共24分」 |
| 选项写成 `A、` | 识别为普通段落，不排四列 | 用 `A.` |
| 用 `___` 手写下划线 | 换字体/打印断线 | 用 `{{答案}}` |
| 例题和解析写在同一段 | PPT 无法拆成两页 | 解析单独起行，用 `【解析】` |
| 把易错点写进解析 | 学生划过去 | 单独一行 `【特别提醒】…`，PPT 会单独出红页 |
| 漏写 `> 来源：` | 讲评课说不清出处 | 每题前加一行来源 |
| 标题里带 `#` 以外的符号 | 不影响，但目录会难看 | 保持简洁 |
