本篇回答的问题：为什么真实教师写的学案/课件读起来"像老师在讲课"，而 AI 教辅读起来"像练习册答案"。

## 1. 短句原则 + 采分点（阅卷视角，最重要）

真实资料明确教"怎么写才得分"：

> **短句原则**：阅卷按"要点独立给分"，一句话里包含几个得分关键词就得几分。因此要用带
> 主谓宾的短句写足信息点——"温度过高，H₂O₂受热分解加快，氧化效率下降"包含三个信息点；
> 而"温度高不好"没有任何得分结构。短句不等于残缺，每个短句必须有主语、有变化、有结果。
>
> **按点作答、分行书写**：一个采分点一行短句，便于阅卷老师快速抓取；不要写成一大段叙述。

**落地规则（写主观题答案/详解时）**：
- 采分点独立成行，一行一个得分点，绝不合并成大段。
- 每个短句带完整主谓宾（谁 + 怎么变 + 结果），杜绝"温度高不好"式残句。
- 分值均摊到采分点：`（3分）` 可标注在要点后，真实卷子常见 `要点1：…（3分）`。

**采分点体例**（历史卷实测）：
```
（1）要点1：文化传播载体：茶叶是中国传统饮食文化的重要组成部分，其传播过程推动了
      不同地区饮茶习俗的形成，促进了区域间、国家间的文化交流。（3分）
  要点2：政治与战略物资：古代是中原王朝巩固边防、开展朝贡外交的重要媒介…（3分）
  要点3：全球贸易商品：是国际贸易体系中的重要大宗商品…（3分）
```
——「要点N：主题词：展开」三层，每层带分值。写主观题答案照此。

## 2. 禁口语 + 规范表述双栏（失分对照）

真实资料把"看着差不多但不得分"的写法逐条点名：

> **绝不口语**："把渣子滤掉""多加点酸"这类表述不得分，要写成"过滤除去不溶性杂质""适当增大酸的浓度"。
>
> 以下是五年真题阅卷中反复出现的失分点，左侧是"看着差不多"的错误写法，右侧是能拿分的规范表述。

**双栏对照体例**（横向表格，左=错误写法（不得分），右=规范表述（得分））：

| 错误写法（不得分） | 规范表述（得分） |
|---|---|
| 把渣子滤掉 | 过滤除去不溶性杂质 |
| 温度高不好 | 温度过高，H₂O₂受热分解加快，氧化效率下降 |
| 取滤液 | 取最后一次洗涤液 |
| 除去沉淀内部的杂质 | 洗涤除去沉淀表面吸附的杂质 |

**落地规则**：
- 学案/课件的"易错警示""答题规范"栏目一律用**双栏对照**（左错右对），不要写成纯文字提醒。
- 触发词：`规范表述`、`错误写法`、`失分点`、`踩坑`、`易错`、`不得分`。
- 陷阱标注要具体到"哪个字是得分关键"：如"取最后一次洗涤液"六个字是得分关键，写成"取滤液"零分。

**坑例**（真实踩坑批注）：
- 踩坑：只写"温度高反应快"不写高温弊端，只能拿一半分，这是阅卷明确扣分点。
- 踩坑："取滤液"零分；"取最后一次洗涤液"才给分。

## 3. 口诀 / 记忆术（对仗压缩）

真实资料爱用**对仗短句**压缩方法，朗朗上口便于记忆：

- 化学·控制温度：**「控温作答要双面，速率产率对能耗」**（升温/降温两面都要答）
- 物理·波动图像三关键：**「一分、一看、二找」**
- 生物·判断遗传方式：**「四步法」**
- 化学·三段式：**「写方程、列三行、找等式」**

**落地规则**：
- 归纳总结处优先给口诀（对仗/数字压缩），再给展开。
- 口诀格式用 scene `> 口诀：…`，渲染成重点强调页。
- 数字式（三步/四看/五诀）是主流：`三段式`、`四看法`、`五种命题形态`。

## 4. 考情分析表（命题趋势 / 考点提取）

政史地化生的复习课/专题课开头几乎都有**考情分析表**——把真题按年份省份列出来、点命题情境：

```
考点：气压带和风带的分布及其对气候形成的作用
┌────┬──────────────────────┬──────────────────────────┐
│年份│ 卷别 / 题号 / 分值     │ 命题情境和角度            │
├────┼──────────────────────┼──────────────────────────┤
│2026│ 云南，14-16题，9分    │ 济南章丘站探空资料示意图   │
│2025│ 江苏，24题，18分      │ 济州岛地形洋流降水量分布图 │
│2024│ 浙江6月，28题，20分   │ 洞庭湖单双季稻生长期差异图 │
└────┴──────────────────────┴──────────────────────────┘
提取考点：1.气压带…（重难点，核心原理） 2.气候特征描述…（重难点，常见考向） 3.全球变暖…（难点）
```

**命题趋势句式**（真实）：
> 命题趋势：情境越发贴近"资源回收+绿色生产"，两大方向固定不变——分离提纯类与原材料转化制备类。
> 设问中"原因、目的、作用"类文字表达题通常占到全题一半以上分值。
> 整体趋势是"重图表、重链条、重真实情境"，对综合思维和图表信息提取能力要求显著提升。

**落地规则**：
- 考情分析 = 表格（年份｜卷别·题号·分值｜命题情境）+ 提取考点（标注重难点/常见考向/难点）+ 命题趋势结论句。
- scene `> 图表：` 已能出表；考情表头固定为「年份 / 卷别题号分值 / 命题情境和角度」。

## 6. 设问引导（问题驱动讲课）

老师不用陈述句堆知识，用**设问**推进：

- 课堂导入：「压缩气体的同时给汽缸加热，气体内能的变化会比单一方式更明显。这是为什么呢？」
- 层层追问：数学「探究1 如何求…？→ 追问1 它的结构特点是什么？→ 探究2 如何求复合函数的导数？」
- 【思考】：「催化剂在反应前后质量保持不变，那么催化剂能否无限循环使用呢？为什么呢？」
- 小组合作：「小组合作，分析'蜀道之难'在诗中是怎样体现的？」

**落地规则**：
- 导入/探究处多用设问（为什么/如何/怎样/试一试/想一想），少用陈述。
- 追问链：`探究N：问题 → 追问：子问题 → 结论`。
- scene `> 引文：`、`> 材料：… | 设问：…` 可承载设问页。

## 7. 过渡衔接（讲课的口头推进）

真实课件正文有大量口头过渡，不像练习册那样生硬切段：

- 承上：「我们已经知道…」「前面学过…」
- 转折：「那么…」「于是…」「反之…」
- 归纳：「因此…」「综上所述…」「总之…」「由此可见…」
- 步骤：「首先…其次…」「第一步…第二步…」

**落地规则**：PPT 页间/学案段落间加一句过渡（可用 `> 引文：` 或正文首句），别让栏目硬切。

## 8. 详解体例（逐项排除式）

选择题详解不是"选C"，而是**逐项排除 + 结尾点题**（真实解析版体例）：

```
【答案】C
【详解】A：无水乙醇属于非电解质，不能电离出自由移动的离子，不具备导电能力，
        无法构成原电池，排除。
      B：两个盛放稀硫酸的烧杯未形成闭合回路，内电路无法导通，不能构成原电池，排除。
      C：含有活泼性不同的电极，电解质为稀硫酸…满足原电池的所有构成条件，正确。
      D：两个电极均为铜，活泼性相同…无法构成原电池，排除。
      故选 C。
```

**落地规则**：
- 每个选项单独一行 `X：理由 + 判定（正确/排除/错误）`。
- 末行 `故选 X。` 收口。
- 主观题详解 = `设问 → 标准表述 → 必含关键词` 三段（真实：「设问→标准表述→必含关键词与失分提醒」编排）。
- 题源标注格式（真题照抄）：`（26-27高二上·河北石家庄·阶段检测）`、`（24-25高二上·辽宁抚顺·期末）`。

## 10. 渲染落地（scene 与栏目）

- `> 口诀：控温作答要双面，速率产率对能耗` → 口诀强调页
