> 物 54+16，化 15+23，生 63+26。下面按「学案长什么样 / 课件怎么走 / 里面讲了什么」写。

## 一、语文

### 学案：《一轮复习文言文〈师说〉2026》（4 723 字）
抬头就是「胶州四中一轮复习（文言文）学案　编号：」，正文四段固定顺序：

| 板块 | 内容（原样摘录） |
|---|---|
| 一、重点文言字词 | 17 条**带原句**：①古之学者必有师 ②师者，所以传道受业解惑也 … ⑰余嘉其能行古道，作《师说》以贻之 |
| 二、词类活用 | 6 组，按「意动/形容词作名词/形容词作动词/名词作动词」归类，每条给例句 |
| 三、特殊句式 | 4 类：判断句（师者，所以传道受业解惑也）／宾语前置（句读之不知，惑之不解）／被动（不拘于时）／状语后置（学于余） |
| 四、文化常识 | ①古代职业称谓（师襄、庖丁、优孟）②六艺两种含义 ③经传 |

后半页是**任务式**：「一、梳理文章论证结构，绘制思维导图」「二、积累一词多义（传/师/道/之/其）」——
课件里对应的就是「壹 文言字词 / 贰 词类活用 / 叁 特殊句式 / 肆 一词多义」四屏。

配套还有《〈师说〉复习题答案版》：12 道基础知识选择题，每题「答案 + 解析」逐项辨析
（如「A项，①兼词…②语气词…故选D」）。这是**学案 + 一课一练**的组合。

### 早读课件（47–69 页，一学期 20 多份，模板几乎不变）
```
温馨提示：全体齐声朗诵（每页读两遍）
→ 早读任务（写明 7:10—7:20 各时段做什么）
→ 古诗文（菩萨蛮·小山重叠金明灭 / 山居秋暝 / 李凭箜篌引 / 客至 / 蜀相）
→ 《六国论》《师说》《劝学》文言字词 + 词类活用（先留空，下一页给答案）
→ 理解性默写（如「《种树郭橐驼传》中"其莳也若子，其置也若弃"…」先空后答）
→ 作文素材：守本固源，破浪前行（【分论点1】【分论点2】【辩证分析】【联系现实】）
```

### 试卷讲评课件
逐题过（第4题…第9题）→【阅卷情况反馈】（学生写成什么样、错在哪）→
「必备知识：结尾的常见类型及作用」「人物形象塑造的方法」→ 变式任务：用刚学的方法重写本卷某题的问题与答案。

**语文的教学法特征**：一文一学案、四板块扫清语言障碍、结构导图 + 学以致用；
早读是独立产品（诵读 + 默写 + 素材），不是学案的附庸。

## 二、数学

### 复习课件（31 份，一讲一份，骨架完全统一）
```
章标题（第一章 集合与常用逻辑用语、不等式 / 第5节 一元二次函数、方程和不等式）
→ 学习目标（1–2 句，"理解…能…"）
→ 目 录
→ 知识诊断自测（判断正误 √× + 填空 3–5 题）
→ 1.概念 / 2.性质 / 3.…（知识梳理）
→ 常用结论与微点提醒
→ 考点聚焦突破：考点一 → 思维建模 → 训练1；考点二…；考点三…
→ 课时对点精练
```
例：第4节《函数的对称性及应用》——考点一 函数的对称性 / 考点二 对称性与周期性 /
考点三 对称性、周期性与单调性，每考点后紧跟「(2025·保定质检)」这类真题训练。

### 新授课（统计、概率章节，另一套骨架）
```
情境导入（"夏日里的温度密码——气温与冷饮销量" / 摸球 / 射击比赛）
→ 问题1 / 思考1 / 追问1（问题串推进）
→ 定义 → 例题1–3 → 方法感悟 / 归纳总结 → 当堂检测 → 课堂小结
```
《5.3.2 函数的极值》就是典型：问题1（导数为 0 的点有什么性质）→ 追问 1/2/3 →
给出极小值定义 → 问题3（极大值一定大于极小值吗）→ 问题4（f′(x₀)=0 一定是极值点吗）。

### 试卷
单选 8×5=40 / 多选 3×6=18 / 填空 3×5=15 / 解答 5 题；答案用【答案】+【详解】，
难题给「方法1 / 方法2」两条路径。

| No.4/5 | 基础检测案 | 一、单词拼写 10（★核心/☆高频）二、词性转换 10 三、句型 四、写作 |

### 讲评课件（64–81 页）
```
I. 听力（易错题号 2.3.4.9.11.14.19.20 + Text 原文）
→ 阅读 A/B/C/D：文章大意 → 结构分析（"第1段【提出问题+亮出方案】""第3段【过渡段】"）
   → 逐题详解 → 必背单词词块 20 个 → 长难句拆解
→ 七选五：分析选项找关键词 → 浏览全文把握结构 → 逻辑信号词 → 思维导图
→ 完形：逐题选项辨析（happened/event/…）
→ 语法填空 → 应用文（版本一/版本二范文）→ 读后续写
```

### 读后续写学案
「文本分析 → conflicts（冲突）→ clues（原文伏笔）→ 结局 → 十句五定写作框架 →
有逻辑的动作链（turn one's head toward… / kneels down beside him）→ 具体动作分解」。

## 四、物理

### 一轮复习课件（第02讲 匀变速直线运动，56 页）
```
第02讲 → [考情表] → 知识点1 定义及分类 → 知识点2 基本公式
→ 考向1 定义及特点（配 2025 真题）→ 考向2 三个公式的选择与应用（含"考向2 参考系的选取"）
→ 知识点1 两个重要推论 → 知识点2 初速为零的规律 → 考向1/2/3
→ 知识点1 自由落体 → 知识点2 竖直上抛 → 考向1/2
→ 知识点1 解题基本思路 → 知识点2 刹车类 → 知识点3 六种思想方法 → 知识点4 多过程
→ 考向1 常规刹车 / 考向2 逆向思维 / 考向3 多过程
```
**规律：知识点 → 考向 → 真题，三段循环**，一讲 4 个知识块。

### 新授课课件（另一套）
```

玻尔假设 / 玻尔解释 / 局限性（5–6 个"探究新知"）→ 例3 → 训练4 → 课堂小结
→ 随堂对点自测 → 课后巩固训练
```

### 单元复习（第四章 光）
单元学习目标 → 单元学习重难点 → 第1–6节 → 题型剖析及针对训练（题型一 折射定律…题型六 双缝干涉）
→ 课堂巩固 → 课堂总结。

高二生物寒假自主学习（2）

## 七、六科对照：学案到底怎么写

| 维度 | 语文 | 数学 | 英语 | 物理 | 化学 | 生物 |
|---|---|---|---|---|---|---|
| 粒度 | 一文一案 | 一考点一案 | 一话题四件套 | 一讲一案 | 一讲一案 | 一章 14 份 |
| 首屏 | 课标/学习目标 | 学习目标 1 句 | 话题 + 主题语境 | 学习目标 1–2 句 | 学习目标 | 必备知识 |
| 主体 | 字词/活用/句式/常识 | 知识诊断 + 考点1–3 | 语法填空 20 + 写作 | 知识点→考向→真题 | 考点+判断正误+典例 | 教材原句填空 + 判断 |
| 例题 | 复习题（选择题） | 思维建模 + 训练 | 阅读/七选五逐题 | 考向配高考真题 | 典例 + 精练真题 | 教考衔接 + 练透考法 |
| 收尾 | 结构导图 + 学以致用 | 课时对点精练 | 话题评测题 | 课时精练 | 巩固练习/真题 | 归纳拓展 |
| 答案形态 | 单独答案版 docx | 【答案】+【详解】 | 逐题详解 + 词块 | 解析 + 答案 | 逐项辨析 | 答案嵌在填空里 |

**共性四点**（六个学科都有，可以直接当硬规范）：
1. 抬头必有归属：学校 + 年级学科 + 文档类型 + 编号｜编写人/审核/时间。
2. 开头必给「学习目标」或「课标要求」，1–3 条，动词开头。
3. 知识部分**一定有留白**（填空、判断√×、或"____"），不是纯讲义。
4. 例题必配**真题出处**（2025·山东卷 / 2026·重庆模拟），且解析给到选项级。
