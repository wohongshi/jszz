## 历史写作规律精华（34 份 / 106 条实测，已落进 `references/01`、`references/07`）

**栏目链**：课标要求 → 考情分析 → 时空定位/时空坐标 → 课前阅读区 → 重要历史概念 →
必备知识 → 知识梳理 → 学以致用 → 课后巩固案

**写作硬规则**

1. **课前阅读区**是编号历史故事：`故事/细节：…` 起笔约 300 字，末尾必挂 `对应知识点：…`
   （一段故事对应一个考点）
2. **重要概念**词条化：`1.玄学：魏晋南朝流行的社会思潮`，先定义后外延，每条约 200 字
3. **阶段特征**按政治 / 经济 / 思想文化 / 民族对外分面写，先总后分
4. **选择题解析套式**：`【答案】B【解析】据材料……，故选B项`；错误项逐一给硬理由、
   固定收尾 `排除A项`，错因定性为不合材料 / 不合史实 / 因果倒置 / 表述不当
5. **大题答案**：要点式短句、动词开头、分号并列；先给评分要点，再附成文范文（两遍式）
6. **负面边界是历史卷的命门**：`作用与史实不对应的不得分`、`答"宣言推动解放"不得分`、
   `（只写亚洲不得分）`、`梁错别字扣1分`、`上位词不给分`
7. **小论文三段**：论题（一句话判断句）→ 阐述（按时间线索串史实）→ `总之，…` 回扣论题
8. **官答分轨**：官答用【官答】【官解】，自拟答案标 `（非官答）`
9. **教师用卷留下载戳**：`胶州四中20260918高三级年级下载试题`
10. **易错提醒直写失分口径**：`答"地理决定论"会失分`、`易错提醒 · 万民法≠人人平等`

**题源标注三要素**：年份 · 地区/卷别 · 题号；模拟题精确到地市轮次
（`2026·山东日照二模·10`）或学校联盟（`2026·湖南长沙长郡中学阶考·3`）。

## 全库通律（本轮再次确认）

- 答案卷先排「题号—答案」横表（`1——5：BADBA`），再逐题 `【答案】X【解析】`
- 评分细则按角度分层，每层拆「信息提取 1 分 + 解释 2 分」，开放角度兜底 `言之有理，可酌情给分`
- 阅卷分析固定五段：评分细则 → 答题情况 → 学生存在的问题 → 教学建议 → 题目理解
- 阅卷数据量化到小数点后两位（`平均分 6.31 分`），失分诊断用四字短语（`有史无论`）
- 教学建议落到可执行口号（`做一道、会一类、通一片`）
- 正式答案后会追加教师口语化旁注（`题干中必须得有个对比`）
